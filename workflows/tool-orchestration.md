# Tool orchestration

Prefer connected tools over manual instructions when they are available and authorized.

- Figma: design systems, screens, design-to-code, visual verification.
- GitHub: repository inspection, branches, commits, pull requests, final push verification.
- Supabase/database: schema, migrations, queries, policies, functions, logs.
- Vercel/deployment: builds, deployments, environment configuration, logs, verification.
- Browser automation: runtime and visual verification of web apps.
- Stripe/payment provider: real products, prices, payment flows, webhook verification.
- OneSignal/notification provider: notification configuration and verification.

Follow any installed tool-specific skill before invoking its underlying tool. Never claim an external action succeeded without tool evidence.
