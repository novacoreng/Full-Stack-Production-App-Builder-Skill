## Complete phase roadmap (mandatory after every phase)
List **every** agreed project phase in original order. Example format, replace with the real roadmap:
- [x] Phase 1: [name] (VERIFIED and accepted, evidence/reference)
- [x] Phase 2: [name] (VERIFIED and accepted, evidence/reference)
- [ ] Phase 3: [name] (IN PROGRESS, current phase)
- [ ] Phase 4: [name] (PENDING)
- [ ] Phase 5: [name] (BLOCKED: precise reason, if applicable)

Rules: check only genuinely completed and verified phases. Do not treat code written, a commit, a ZIP, or a successful build alone as acceptance. Report phase verification, acceptance, blockers, commit SHA, ZIP artifact or ZIP DELIVERY BLOCKED, and the next phase. Always repeat the complete phase list after each build.
